Основной пример

Form Field для нативного input

Компонент собирает label, prefix, suffix, hint и error вокруг обычного поля ввода. Reactive Forms и HTML-атрибуты остаются на самом input.

Название проекта AZ Prefix и suffix передаются через content projection. Название обязательно.

Label

ui-label
ФИО Введите от 2 до 40 символов. {{ nameErrorText }}

Prefix

uiPrefix
Email @ Обычные атрибуты остаются на input. Введите корректный email.

Error

ui-error
Код ! Формат: две буквы, дефис, четыре цифры. Используйте формат AB-1234.

Disabled

NgControl
Источник данных DISABLED Обертка читает disabled из NgControl.

Hint

ui-hint
Описание Textarea использует ту же директиву и ту же обертку. {{ descriptionControl.value.length }}/{{ descriptionMaxLength }} {{ descriptionErrorText }}

Suffix

uiSuffix
Поиск Q В suffix можно передать кнопку, иконку или текст.
